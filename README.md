# Alien Survivor

**Native Godot source prototype. Flat retro 2D. Steam first; mobile later.**

The `feat/first-playable` branch adds the first implementation. It is not a finished game, final art sample, published Steam build, or tested mobile port.

## Implemented source

One industrial arena, one automatically firing rifle with manual aim override, one directional runner, obstacle-aware movement, swept bullet collisions, health/contact damage, XP, three capped upgrades, five-minute extraction, pause/death/results/restart, original procedural sprite placeholders, synthesized sound effects, keyboard/controller input paths, touch gestures, local settings, and repeatable 25/50/100-enemy diagnostic scenarios.

This is a bounded first playable plus a small XP/upgrade loop, not the full planned game. No boss, extra guns, meta progression, run suspension, Steam SDK, accounts, backend, cloud save or monetization. All runtime assets are generated by the source; there is no art pack to buy or download.

## Open and run

Install **Godot 4.7.2 standard** (not .NET), import `game/project.godot`, and press **F5 / Run Project**. The title screen should offer **DEPLOY / FIVE-MINUTE RUN**. All scripts use GDScript and the Compatibility renderer.

Command-line equivalent:

```sh
godot --path game
```

Controls: WASD / left stick to move; firing and targeting are automatic. Hold left mouse button or move the right stick to override aim. Escape / Start pauses. F3 shows real diagnostic counters. F4 shows touch guides. On touchscreens, drag on the lower left to move and on the lower right to aim. Use Settings to change touch radius, mute, gore and shake. Real phone/controller testing is still required.

After leaving a menu, release held movement/aim controls once before moving. This neutral gate prevents stuck input or menu clicks becoming immediate shots. Losing focus pauses the run. Exiting the application loses the current run; only preferences are persisted.

## Tests

```sh
python3 tools/check.py --static-only
python3 tools/check.py --godot /path/to/godot
```

The second command requires the pinned editor. It imports the actual project, runs gameplay/settings tests, verifies a deliberately failing test returns failure, and boots the complete scene in a headless smoke test. Missing Godot is a nonzero BLOCKED result, never a passing test. Headless success is not visual or device validation.

The workflow `.github/workflows/prototype.yml` performs those checks on push/PR. It downloads the official pinned Linux editor, verifies its published digest, and needs no game backend, secrets, marketplace action, or paid plugin.

## Export after checks pass

Install the **matching 4.7.2 export templates** in the Godot editor. From the repository root:

```sh
python3 tools/export.py windows --godot /path/to/godot
python3 tools/export.py linux --godot /path/to/godot
```

Outputs go under `builds/`. These are unsigned development releases, not Steam submissions. The script stops if engine checks fail or no nonempty executable is created.

The Android preset is debug-only and additionally requires a configured Android SDK, JDK and local debug keystore:

```sh
python3 tools/export.py android --godot /path/to/godot
```

No signing credentials are included. iOS export is not configured here; it requires a later macOS/Xcode/device check. Do not publish an Android or Steam listing on the basis of these presets alone.

## Source map

- `game/scripts/simulation.gd`: authoritative gameplay and upgrade state.
- `game/scripts/arena.gd`, `spatial_grid.gd`: geometry, shared navigation and nearby queries.
- `game/scripts/input_router.gd`: keyboard/controller/touch intent.
- `game/scripts/arena_view.gd`, `sprite_factory.gd`: replaceable original placeholder visuals.
- `game/scripts/hud.gd`, `sound.gd`: native menus/HUD and original sound synthesis.
- `game/scripts/settings.gd`: validated preferences with backup recovery.
- `game/data/default_balance.tres`: read-only base tuning; upgrades do not mutate it.
- `game/tests/run_tests.gd`: executable engine-side tests.
- `tools/`: local checks, CI engine installer and exports.

The existing `docs/` and `AGENTS.md` on GitHub remain planning/agent context. Some ideas there describe later milestones, not implemented capabilities. The source package supplied in the conversation contains the implementation and this guide, not a second copy of every planning document.

## Art and rights

The placeholder images are generated in `sprite_factory.gd`; sounds in `sound.gd`. No original Alien Shooter art, sounds, source code or title branding was extracted. No font files or proprietary marketplace assets are bundled. These placeholders are for testing, not the approved final visual direction. No blanket open-source licence has been selected for the owner's game.
